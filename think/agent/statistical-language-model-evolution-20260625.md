# 统计语言模型脉络:链式法则 → 马尔可夫假设 → N-gram → MLE

> 来源:个人思考(对话整理)
> 收录时间:2026-06-25 22:10 CST

---

## 一、一条主线

深度学习兴起之前,语言模型的主流是统计方法。它的发展可以串成一条清晰的逻辑链:

```
① 链式法则(理论框架)
   └─ ② 马尔可夫假设(简化思想)
        └─ ③ N-gram 模型(落地的模型)
             └─ ④ MLE(估计每步概率的工具)
                  └─ 毛病:没见过的搭配 = 0
                       └─ 平滑(打补丁)
                            └─ 扛不住长距离依赖 → 神经网络 / Transformer 接棒
```

**分清「思想 / 模型 / 工具」三个层面**,是理解这条线的关键:

| 层次 | 名称 | 角色 | 一句话 |
|------|------|------|--------|
| ① 理论 | 链式法则 | 该算什么 | 整句概率 = 每步「猜下一个词」连乘 |
| ② 假设 | 马尔可夫假设 | 凭什么简化 | 下一个词只跟最近几个词有关 |
| ③ 模型 | N-gram | 落地的模型 | 把假设实现成「只看前 N-1 个词」 |
| ④ 估计 | MLE | 怎么填数 | 概率 = 数次数 ÷ 总次数 |

①② 是「思想」,③ 是「模型」,④ 是「算概率的工具」——三者不是一代更比一代偷懒,而是不同层面。

---

## 二、① 链式法则:整句概率 = 接龙连乘

一句话出现的概率,等于从左到右每个词在「前面所有词」已知前提下的条件概率,全部相乘:

$$P(S) = P(w_1) \cdot P(w_2 \mid w_1) \cdot P(w_3 \mid w_1, w_2) \cdots P(w_m \mid w_1, \dots, w_{m-1})$$

- 竖线 `|` 读作「在……条件下」,右边是已知前文,左边是正在猜的下一个词。
- $P(w_n \mid w_1,\dots,w_{n-1})$ = 已知前文,紧接着第 $n$ 个词是 $w_n$ 的概率。
- 本质是**接龙**:每步「拿着已写好的前文,猜下一个词」,全部乘起来 = 这句话有多「像人话」。

**例**:句子「我 爱 你」

$$P(\text{我爱你}) = P(\text{我}) \cdot P(\text{爱} \mid \text{我}) \cdot P(\text{你} \mid \text{我爱})$$

> 链式法则理论上完全正确,但「老老实实算」算不动:前文越长,这一整串词在语料里出现次数越可能是 0,根本估不出来(**数据稀疏**)。这是它的死穴。

---

## 三、② 马尔可夫假设 + ③ N-gram:偷懒换可算

**马尔可夫假设**:猜下一个词,不用看全部前文,只看前面 N-1 个词就够了——「最近几个词」比「很久以前的词」重要得多。

基于此实现的模型就是 **N-gram**:

| 名称 | 看几个词 | 公式近似 |
|------|---------|----------|
| Unigram(1-gram) | 不看前文 | $P(w_n)$ |
| Bigram(2-gram) | 只看前 1 个 | $P(w_n \mid w_{n-1})$ |
| Trigram(3-gram) | 只看前 2 个 | $P(w_n \mid w_{n-2}, w_{n-1})$ |

对比:

$$\underbrace{P(w_n \mid w_1,\dots,w_{n-1})}_{\text{前文太长,数不出来}} \quad\Rightarrow\quad \underbrace{P(w_n \mid w_{n-1})}_{\text{只数两词搭配,语料里多得很}}$$

> 本质:**砍掉长距离依赖,用一点精度换来算得动。** 代价是记不住远处信息(如「我出生在中国……所以我会说 ___」,N-gram 看不到那么远的「中国」,猜不出「中文」)。

---

## 四、④ MLE:具体怎么把概率数出来

N-gram 需要知道每个搭配的概率,**MLE(最大似然估计)** 就是算它的具体办法——数次数 ÷ 总次数:

$$P(\text{爱} \mid \text{我}) = \frac{\text{「我 爱」出现次数}}{\text{「我」出现总次数}} = \frac{30}{100} = 0.3$$

> 直觉:在所有出现「我」的场合里,有多大比例后面跟的是「爱」。

**注意**:MLE 不是「N-gram 之后更偷懒的下一代」,而是**藏在 N-gram 内部**的估计手段。

### MLE 的硬伤,催生下一步

只要某个搭配在语料里没出现过,MLE 就直接算出概率 = 0。例如「我 爱 西瓜」完全通顺,但语料里恰好没出现「爱 西瓜」→ 判概率为 0 → 整句连乘后变 0,显然不合理。

- 为补这个洞 → **平滑(smoothing)**:给没见过的搭配也分一点点概率。
- 平滑也扛不住长距离依赖 → **神经网络 / Transformer 登场**(靠泛化能力,没见过的组合也能合理估计)。

## 附录:自我思考

- 最大的收获是**分层**:链式法则、马尔可夫假设、N-gram、MLE 不是「一代比一代偷懒」的时间线,而是**理论 / 假设 / 模型 / 工具**四个不同层面叠在一起。一开始我误以为 MLE 是 N-gram 的「下一代」,其实它是 N-gram 内部用来估概率的工具。
- 这条链每一环都是**「正确但不可行 → 做个妥协 → 妥协带来新缺陷 → 再补」**的循环:链式法则正确但算不动 → 马尔可夫假设截断前文 → MLE 数次数 → 没见过就是 0 → 平滑 → 长距离依赖仍解决不了 → 神经网络。技术演进往往就是这样「补洞」补出来的。
- 与上一篇 [[llm-training-process-20260625]] 呼应:现代 LLM 的预训练目标「预测下一个词」,本质仍是链式法则里的 $P(w_n \mid \text{前文})$,变的只是「怎么估计这个条件概率」——从数次数升级成了神经网络拟合。
