## 正文

想给全家设备一次性去广告，在软路由上装好拦截，结果广告照样在？我也卡过——多半不是没装好，是踩了下面几个坑。零基础能照做，先收藏。

① **原理一句话**：在软路由上拦广告靠的是 DNS——设备查广告域名时直接返回「查无此人」，广告就加载不出来。所以全家设备只要拿这台软路由当 DNS，就一起干净。（我的环境：OPNsense + `[你用的：Unbound DNSBL / AdGuard Home 插件]`）

② **怎么开（简版）**：`[开 DNSBL / 装 AdGuard 插件]` → 加几个广告黑名单 → 把 DHCP 下发的 DNS 指向这台软路由。基本就通了。

③ **【坑一·最常见】装了没效果，八成是设备根本没用你的 DNS**：现在手机、浏览器很多默认开了 DoH（加密 DNS，Chrome、iOS 都有），会绕过你的拦截直连公共 DNS。表现就是「我明明装了，广告还在」。→ 关掉设备/浏览器的「私人 DNS / 安全 DNS」，或在防火墙把外部 53/DoH 拦掉强制回流。

④ **【坑二】IPv6 漏网**：只配了 IPv4 的 DNS，但设备走 IPv6 上网 → 照样绕过。→ IPv6 的 DNS 也要指向软路由，或先关 IPv6 测试。

⑤ **【坑三】别期待 100%**：拦太狠会有网站/APP 打不开（加白名单）；而且 DNS 层拦不掉「和正文同域名」的广告（典型：YouTube APP 内广告、开屏广告）。
