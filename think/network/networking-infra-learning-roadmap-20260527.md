# 网络 / 基础设施 / 运维 学习路线图（为「会编程但网络弱」定制）

> 来源：个人思考 + 学习规划
> 收录时间：2026-05-27 17:20 CST
>
> 适用对象：有编程基础、网络薄弱、想往网络/基础设施/运维方向「猛学」。
> 配套实战场：家里的 OPNsense + 待搭的 WireGuard（见 `wireguard-home-vpn-setup-guide-20260527.md`）。

---

## 心法：三条铁律（决定你学得猛不猛）

1. **三角循环学习法**：每个概念都走「**读理论 → Wireshark 抓包看真实流量 → 在自己网络里动手造一遍**」。只读会忘，只做不懂，三者咬合才是最快的路。
2. **把编程当杠杆**。你会写代码，这是普通网工没有的优势：
   - 学协议就**读 RFC、用 socket 写个最小实现**——亲手造过的协议永远忘不了。
   - 学配置就**用脚本/IaC 把它代码化**，顺便练运维。
   - 看到"魔法"就追到底层源码，别停在"会用"。
3. **每个阶段有「毕业标准」**，达标再走下一阶。标准都是"能动手做出来 / 能在白板讲清楚"，不是"看过"。

## 阶段 0：搭好学习环境（半天）

- [ ] 装 **Wireshark**（你的"网络显微镜"，全程都要用）
- [ ] 准备一台 **Linux 实验机**：Proxmox/VirtualBox 开个 Ubuntu VM，或一台闲置机器。要能随便搞坏重装。
- [ ] 盘点 homelab 资产：OPNsense（已有）、有没有可装虚拟化的主机、有没有交换机。
- [ ] **毕业标准**：用 Wireshark 抓到自己打开一个网站时的数据包，能认出里面有 DNS 查询和 TCP 连接（看不懂内容没关系，能"看见"就行）。

## 阶段 1：网络地基 🔥（4–8 周，核心）

按下面 6 小节顺序推进。**每节都按「学什么 / 抓包实验 / 在 OPNsense 动手 / 毕业标准」走完再下一节。**

### 1.0 主框架：分层模型 + 一个网页请求的全过程
- **学什么**：TCP/IP 五层模型，以及"你在浏览器敲 google.com 回车后，每一层到底发生了什么"。这是挂所有知识的钩子。
- **首选资源**：《**网络是怎样连接的**》(户根勤) —— 跟着一个网址请求走完全程，建立直觉的神书，先看这本最不劝退。
- **毕业标准**：能在白板上把"敲回车 → 看到网页"的全过程分层讲一遍。

### 1.1 网络层：IP / 子网 / CIDR / 路由 / NAT ★最核心★
- **学什么**：IP 地址、私网段、**子网划分与 CIDR**（务必练到看 `/23`、`/24` 秒懂范围）、路由表、NAT 的三种类型。**这一节是 VPN、软路由、公司网的共同命根子。**
- **用编程加速**：写个小脚本做"IP + 掩码 → 网段/广播/可用范围"的计算，比纯背公式记得牢。
- **抓包实验**：抓局域网内 ping 网关的包，看源/目的 IP。
- **OPNsense 动手**：看懂它的路由表（`系统 → 路由`）和 NAT 规则（`防火墙 → NAT`）。回头看你之前问的"VPN 路由环路"，此刻应该秒懂了。
- **毕业标准**：给定一个网段 `10.0.0.0/22`，能口算出有多少地址、范围是多少、能不能和 `10.0.2.0/24` 共存。

### 1.2 链路层：MAC / 交换机 / VLAN / ARP
- **学什么**：MAC 地址、交换机怎么转发、**VLAN（公司网隔离部门/设备的核心手段）**、ARP 协议。
- **抓包实验**：抓 ARP 请求/应答，看"广播问 IP 对应的 MAC"。
- **OPNsense 动手**：在 `接口 → 其它类型 → VLAN` 划一个 VLAN，体会二层隔离。
- **毕业标准**：能讲清"VLAN 为什么能让同一台交换机上的设备互相隔离"。

### 1.3 传输层：TCP vs UDP / 端口 / 三次握手
- **学什么**：TCP 三次握手/四次挥手、可靠传输原理、UDP 区别、端口的意义。
- **用编程加速**（你的强项发力点）：用 socket 写一个最小的 TCP 客户端+服务端（Beej's Guide）。**自己 send/recv 一遍，TCP 就刻进脑子了。**
- **抓包实验**：抓一次 TCP 连接，亲眼看到 SYN → SYN-ACK → ACK。
- **毕业标准**：能解释"为什么 WireGuard 只用 UDP，而 OpenVPN 能用 TCP 伪装成 HTTPS"（呼应你最初的问题）。

### 1.4 应用层：DNS / HTTP/HTTPS / TLS
- **学什么**：DNS 解析全过程（递归/迭代）、HTTP 请求结构、**TLS 握手与证书**。
- **抓包实验**：抓 DNS 查询；抓 HTTPS 的 TLS 握手（看到证书交换）。
- **OPNsense 动手**：看它内置的 Unbound DNS；可顺手了解 DNS 过滤。
- **毕业标准**：能讲清"访问 https 网站时，浏览器怎么确认对方不是假冒的"。

### 1.5 安全与加密：防火墙 / 对称与非对称加密
- **学什么**：有状态防火墙原理、对称加密 vs 非对称加密、公私钥、数字签名。
- **OPNsense 动手**：读懂并自己写几条防火墙规则。
- **毕业标准**：能讲清"WireGuard 的公私钥是怎么做到既加密又验明身份的"——讲完这一条，你就**真正理解 VPN 和代理了**，不再是照菜谱。

### 🎓 阶段 1 毕业大考（达标才算地基过关）
- [ ] 白板上完整讲出"手机访问 google.com"从应用层到物理层的全过程。
- [ ] 在 OPNsense 上**不查文档**完成：划一个 VLAN + 写一条防火墙规则 + 把 WireGuard 那份菜谱独立跑通。
- [ ] 能口算常见 CIDR 子网。

**资源套餐（阶段 1 通用）**：
- 主教材：《**计算机网络：自顶向下方法**》(Kurose) —— 经典，从应用层往下讲，可读性极强。
- 课程（强烈推荐你这种 coder）：**Stanford CS144** —— 课程项目是**亲手用 C++ 实现一个 TCP**，对会编程的人是封神级训练。
- 速查/趣味：**Julia Evans 的 wizardzines 网络小册子**（专为程序员写的网络科普，极友好）。
- 工具：**Wireshark** 全程相伴。

## 阶段 2：Linux 网络与系统（3–4 周，运维内功）

运维方向，Linux 是吃饭家伙。你会编程，这阶段能走很快。

- [ ] **现代命令**：`ip`（取代 ifconfig）、`ss`、`nftables`/`iptables`、`tcpdump`。
- [ ] **网络命名空间 (network namespace)**：这是**容器网络（Docker/K8s）的本质**。手动建两个 namespace 用 veth 连起来、配路由、做 NAT —— 你会突然看穿 Docker 的网络魔法。
- [ ] **systemd / 服务管理 / 日志（journalctl）**。
- [ ] **用编程加速**：写脚本自动化常见操作；读一读 `wg-quick` 这种 shell 脚本，看它到底帮你干了啥。
- **首选资源**：《鸟哥的 Linux 私房菜》或任一系统的 Linux 运维教程 + Linux 网络相关章节。
- **毕业标准**：手搓两个 network namespace，用 veth pair 连通，并让其中一个通过 NAT 访问外网。**做到这个，你对"软路由/容器/VPN 转发"的底层就全通了。**

## 阶段 3：把家变成数据中心 — homelab 实战（持续滚动）

地基打牢后，这阶段是"爽"和"出活"的阶段，也是 infra/ops 简历的硬通货。

- [ ] **OPNsense 深用**：把家庭网络划成 ≥3 个 VLAN（信任设备 / IoT / 访客），写策略让它们按需隔离；用上 IDS/IPS、DNS 过滤；VPN 此时你已能随手配。
- [ ] **虚拟化**：装 **Proxmox**，把闲置主机变成自己的"私有云"，随便开关 VM。
- [ ] **容器**：**Docker** + docker-compose，自托管几个服务（如 AdGuard Home 做内网 DNS、一个 NAS 面板、监控）。
- [ ] **反向代理**：用 **Caddy / Nginx** 给内网服务配域名 + 自动 HTTPS。
- [ ] **毕业标准**：家里跑起一套"分了 VLAN 的网络 + 至少一个自托管服务 + 内网域名访问"，并能画出整套网络拓扑图。

**社区/资源**：OPNsense 官方文档、Proxmox 文档、r/homelab、r/selfhosted。

## 阶段 4：运维工程化（方向深入，奔向 SRE / 网络工程师）

从"手动玩"升级到"工程化、可复现、可观测"——这是运维和"会配两下"的分水岭。

- [ ] **基础设施即代码 (IaC)**：用 **Ansible** 把 homelab 的配置代码化（一键重建）。进阶看 Terraform。
- [ ] **可观测性**：搭 **Prometheus + Grafana**，监控家里所有设备的 CPU/网络/温度，做告警。
- [ ] **自动化 & 备份**：定时任务、配置版本化（git）、自动备份。
- [ ] **进阶方向（按兴趣选）**：
  - 想往云原生/SRE → **Kubernetes**（在 homelab 跑个 k3s）。
  - 想往网络工程 → 深入 BGP/OSPF、用 GNS3/EVE-NG 模拟企业网络拓扑，了解证书路线（如网络/Linux 认证，**别为考证而考证，当作检验地图用**）。
- **首选资源**：《SRE: Google 运维解密》（理念）、Ansible/Prometheus 官方文档。

## 节奏建议

- **每周固定投入**比"突击一天"有效得多。能保证每周 8–10 小时就很猛了。
- **可以快进的**（因为你会编程）：socket 编程、脚本自动化、读配置/源码、IaC——这些对你是顺风。
- **不能快进的**：子网计算、路由/NAT 的心智模型、抓包实操——必须慢下来练到"肌肉记忆"。
- **节流警告**：别一上来就钻进 K8s / 各种花哨自托管。**没有阶段 1 的地基，越往上越虚。**

## 如果只能记住一句话

> **网络/运维的一切，本质都是「IP 包从哪来、到哪去、被谁挡、怎么回来」。** 把阶段 1 的网络层（IP/路由/NAT）和 Linux 转发吃透，VPN、代理、软路由、OPNsense、公司网，全是这套地基的不同摆法。

## 附录：自我思考

**1. 为什么把"地基"压得这么重？**
我列的 5 样东西（VPN/代理/OPNsense/软路由/公司网）之所以在初学者眼里像 5 个孤岛，是因为缺了底下那块共享地基。一旦把"IP/子网/路由/NAT + Linux 转发"打通，它们会塌缩成同一套原理的不同应用。所以这份路线刻意把 60% 精力压在阶段 1，宁可慢，也不让人带着"照菜谱"的错觉往上爬——上层玩得越花，地基的窟窿越致命。

**2. 把"会编程"当成最大变量。**
同样学网络，程序员和非程序员的最优路径不一样。对会写代码的人，"亲手实现一个 TCP（CS144）""手搓 network namespace""读 wg-quick 源码"这类做法，能把抽象协议变成可触摸的东西，学习速度数量级地快。这份路线刻意在每个阶段标注"用编程加速"的点，就是要把这个优势榨干。

**3. 毕业标准为什么都是"能做/能讲"而非"看过"。**
"看过一遍"是学习最大的自欺。把每阶段的出口定义成"白板能讲清"或"动手能造出来"，是为了逼出真实理解——这也呼应心法第一条的三角循环：读过的东西，必须经过抓包验证和动手复现，才算真的进了脑子。

**4. homelab 是这条路最大的运气。**
大多数人学网络/运维卡在"没有真实环境练手"。而你手里已经有 OPNsense、有自建 VPN 的需求、有想猛学的动机——这等于自带一个生产级实验场。这份路线的每一阶段都尽量挂回你自己的设备，就是要让"学"和"用"在同一个网络里闭环。
