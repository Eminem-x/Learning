## 4. 内容主轴（只留一条，砍掉其它板块）

**主轴 = 全链路演进**。它天然有叙事弧，且每一步被上一步的真实痛点逼出来——这就是差异化。

```
Go 起服务（裸机）→ 开防火墙 / IP 直连
  →（痛：环境不可迁移、手动维护累）
域名 + DNS + nginx + certbot
  →（痛：环境漂移）
Dockerfile → Docker Compose
  →（痛：手动部署慢、易错）
CI/CD（Jenkins + Harbor）
  →（痛：单点 / 扩展）
多实例 → k8s → consul
  →（业务驱动）存储矩阵（按"为什么引入"逐个上）
  → VPC / 堡垒机 / 监控告警 / 日志 trace / 异步·定时·延时任务
```

**两遍走法（关键）：**

- **第一遍走浅**：你强的部分（裸机 / nginx / docker / compose / 基础 CI）直接输出。**目的是攒受众、立人设，不指望它值钱**（这段免费替代多）。
- **第二遍钻深**：k8s / consul / harbor 那层，用 **「我来真把它独立搭通、搞懂」** 的 build-in-public 姿态补深，边补边记录。**补深同时长出三样：真实力 + 值钱内容 + 信任。**

**纪律：内容别跑到真实水平前面。** "我在学 k8s" 能发；"我教你 k8s" 必须你真搭通了。死亡区里最差的内容，是没吃透时硬装教学——又免费又出错。

**配菜（不立板块，揉进主轴）：** more than code、技术人的生活/思考——做人格点缀，增信，低频。

**已砍：** news（无护城河、AI 免费做、纯增维护负担）、生活/咨询作为"并排板块"。

## 5. 品牌人设（二选一，已选）

旧版的「强者文化 / 咨询必须付费」与「more than code / 帮新人共鸣」**互相打架**，受众能闻出拧巴；且起步期没受众，摆"强者"姿态会掐死本就稀薄的流量。

**起步期定调：共鸣 + 帮新人 + 慷慨。**
- "强者文化 / 付费墙优先" 是成名后才用得起的姿态，**现在收起来**。
- 慷慨给价值 → 建信任 → 信任沉淀成受众资产 → 资产再变现。顺序不能反。

## 6. 平台与漏斗（砍到能扛住的最小集）

旧版"B站 + 抖音 + 小红书"三线作战，前期是自杀。**先活下来，再谈分发。**

**漏斗（国内现实，绕不开微信生态）：**

```
内容发现层      信任沉淀层         资产/复利层
B站(主) ───►  公众号 / 微信群 ───►  知识星球（年费）
抖音/小红书(后期切片导流)            课（一次做多次卖）
                                    咨询（点缀，不主推）
```

- **发现层先做一个**：建议 B 站（系列长视频最配全链路演示）。跑顺了再加抖音切片。
- **信任沉淀**：公众号承接，把视频观众变成可触达的人。
- **联系入口的取舍**：你偏好飞书（不用微信），但**大众受众全在微信生态**，飞书是工作工具、个人学习社群几乎没人用。坚持飞书 = 在转化环节自加摩擦。
  - 建议：**对大众用微信生态（公众号 + 微信群 + 知识星球）**；飞书仅保留给高端 B 端咨询。别让个人偏好挡在分发前面。

## 7. 变现模型（重仓可 scale 的，咨询只做点缀）

| 层 | 形式 | 价格 | 作用 | 是否可 scale |
|---|---|---|---|---|
| 免费层 | B站视频 / 公众号文章 / 切片 | 0 | 获客、建信任 | — |
| **复利层（主）** | **知识星球（年费社群）** | **¥99–199/年** | **循环收入、核心资产** | ✅ 高 |
| 课层 | 全链路一口价经验课 | ¥99–199 | 一次做多次卖 | ✅ 高 |
| 咨询层（点缀） | 付费答疑 / 架构评审 | ¥200–2000/次 | 高客单 + 背书 | ❌ 卖时间 |

**为什么这样排：** 你的真实目标是杠杆/被动收入。**咨询是最不 scale 的（卖时间），不能当主力**，否则只是换个更累的班上。**星球 + 课才 scale。**

**收入参照（真实锚点）：**
- ¥199/年 星球 × 1000 付费成员 = **20 万/年、且循环** → 背后约需 3–10 万受众。
- 课：掘金小册爆款几千~上万份，与平台五五分；绝大多数远低于此。
